# MetaSalon

Tarjeta del Modo Aula que muestra el ajolote del salón, la meta colectiva de estrellas y, aparte, el aviso privado de progreso de cada alumno.

## Meta colectiva
- Barra de progreso con `radio-pill`: relleno `sol`, fondo `bloqueado`, contorno de 2px en `tinta`.
- Texto con el avance (“★ 36 de 60”) y el premio de la meta (“Accesorio nuevo para el ajolote”).
- Todos suman; nunca aparecen nombres ni aportes individuales.

## Aviso privado de progreso
- Mensaje corto al alumno con la voz del explorador (“¡Subiste en multiplicación, explorador!”).
- Fondo `magia-suave` y etiqueta “Solo lo ven Luna y su maestro”.
- Aparece la próxima vez que el alumno se conecta; no se proyecta nunca en el salón.

## Reglas
- Sin rankings, sin comparaciones entre alumnos ni entre equipos.
- El ajolote del salón se muestra feliz o celebrando según la meta.
