# EscanerCaptura

Pantallas para obtener la foto del ejercicio: captura y recorte.

## Captura
- Visor con esquinas marcadas y el texto “Aquí va tu cuaderno”.
- Dos botones de ancho completo: **Tomar foto** (botón principal) y **Elegir de galería** (botón suave).
- Consejos cortos arriba del visor: “Una operación por foto, con buena luz”.

## Recorte
- La foto se muestra con un marco punteado `pista` y cuatro agarraderas de 24px.
- Solo se envía lo que queda dentro del marco.
- Botones: **Enviar al ajolote** (principal) y **Volver a tomar** (suave).

## Reglas
- Áreas táctiles de 48px como mínimo.
- Los consejos no regañan: “Con buena luz se lee mejor”, no “La foto está oscura”.
- Valor inicial: la foto se comprime a menos de 300 KB antes de guardarse o enviarse.
