# PanelMaestro

Resumen que ve el maestro al terminar una prueba del Modo Aula. Está pensado para leerse en cinco segundos y decidir qué enseñar mañana.

## Secciones
1. **Resultado del grupo:** cuántos alumnos acertaron, con una barra.
2. **Errores más comunes:** cada error típico con su barra y el número de alumnos. Si el maestro no marcó errores, solo se muestran aciertos y fallos.
3. **Qué reforzar mañana:** una sugerencia breve que apunta al apoyo visual de la escalera (por ejemplo, volver a las monedas).
4. **Alumnos que necesitan apoyo:** apodos en chips, siempre con la etiqueta “Privado: solo tú lo ves”.
5. **Progreso de cada alumno:** avance por concepto con marcas, solo cuando hay varias sesiones.

## Reglas
- Barras en `magia` sobre `magia-suave`; el texto nunca depende del color.
- Nunca se proyecta: el panel es del maestro. La pantalla del salón solo muestra la meta colectiva.
- Sin ordenar alumnos por resultado; la lista de apoyo va en orden alfabético.
- Apodos o códigos, nunca nombres completos.
